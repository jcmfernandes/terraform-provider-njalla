# njalla_record_dynamic Resource

Njalla `Dynamic` DNS record for a given domain. Njalla generates a key that
updates the record's address through its DDNS endpoint.

## Example Usage

```hcl
resource njalla_record_dynamic example-dynamic {
  domain = "example.com"
  name = "example-name"
}
```

## Argument Reference

* `domain` - (Required) Specifies the domain this record will be applied to.
* `name` - (Optional) Name for the record. Default is `@`.

~> **Note** Changing any argument forces the existing record to be deleted
and created again, which generates a new key.

## Attributes Reference

* `id` - Njalla ID for this record.
* `key` - (Sensitive) DDNS update key generated by Njalla.
